# OCR Desktop App — рабочая логика кассира

## Папки и статусы сканов

Приложение использует структуру внутри `scans/`:

- `scans/inbox` — **только новые необработанные** сканы от сканера.
- `scans/processed` — сканы, успешно прошедшие OCR.
- `scans/failed` — сканы, по которым OCR завершился ошибкой.

Сценарий для оператора:
1. Сканер сохраняет пачку бланков в `scans/inbox`.
2. В приложении нажимается кнопка **«Запустить OCR новых сканов»**.
3. Результат распознавания пишется в `output.csv`.
4. Файлы автоматически перемещаются:
   - успешно обработанные -> `scans/processed`
   - при ошибке пайплайна -> `scans/failed`

Дополнительно ведется `scans/recognized_history.csv` с историей запусков.

## Обязательный функционал, закрытый в интерфейсе

1. **Коррекция координат ячеек** — кнопка запускает `scripts/02_configurator.py`.
2. **Коррекция распознанных бланков / создание dataset_review** — кнопка запускает `scripts/interactive_trainer.py`.
3. **Запуск invert_dataset_review.py** — отдельная кнопка.
4. **Дообучение модели с кастомным EPOCHS** — поле `EPOCHS` + запуск `scripts/train_model.py --epochs N`.
5. **Открытие папок** `dataset_external`, `dataset_review`, `scans/*` — отдельные кнопки.
6. **Перевод ранее необработанных сканов в CSV** — через `scripts/08_process_scans_batch.py`.

## Логика выгрузки в CRM без дублей

Добавлен отдельный шаг **«Сформировать CSV только новых клиентов»** (`scripts/09_export_new_clients.py`):

- читает текущий `output.csv`;
- считает отпечаток клиента (`client_fingerprint`) по нормализованным полям:
  - ФИО
  - дата рождения
  - телефон (если есть)
- сравнивает с `crm/crm_sent_registry.csv`;
- в выгрузку `crm/exports/crm_new_clients_*.csv` попадают только новые записи;
- новые записи добавляются в реестр отправок.

Таким образом оператор может безопасно повторно запускать OCR и выгрузку, не отправляя одних и тех же клиентов в CRM второй раз.

## Запуск desktop-приложения

```bash
python scripts/desktop_app.py
```

## Сборка в `.exe` (Windows)

Рекомендуемый инструмент: `pyinstaller`.

```bash
pyinstaller --noconfirm --windowed --name OCRDesk scripts/desktop_app.py
```

Для удобства добавлен шаблон `scripts/build_exe.bat`.
